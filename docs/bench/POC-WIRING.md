# Bench PoC wiring (rev 2026-10-15)

Diagram: `docs/bench/poc_wiring.png` (generated by `tools/bench/wiring_diagram.py`).

## Hub: ESP32-S3-DevKitC-1 N16R8

| GPIO | Function | Connects to |
|---|---|---|
| 4 | TWAI TX | CAN board #1 CTX |
| 5 | TWAI RX | CAN board #1 CRX |
| 3V3 / GND | power | CAN board #1, pot ends, keypad common |
| 1 | ADC (dimmer) | pot wiper; pot ends to 3V3 and GND |
| 2 | input, pull-up, active low | headlamp switch to GND (closed = lights on) |
| 6 | PWM out (fake VSS) | jumper to GPIO7 |
| 7 | PCNT input (VSS) | from GPIO6 |
| 8, 9, 10, 11 | membrane keypad rows R1–R4 | ribbon pins 1–4 |
| 12, 13, 14, 15 | membrane keypad cols C1–C4, internal pull-ups | ribbon pins 5–8 |
| USB-C (native) | power + flashing | PC |

Avoid: GPIO0/3/45/46 (strapping), 19/20 (USB), 26–37 (flash/octal PSRAM on N16R8), 38/48 (RGB LED, depends on board revision).

Membrane keypad map (owner 2026-10-16: everything on the membrane pad for now; the Blink is deferred): 1 = temp coolant/oil, 2 = fuel level/ethanol, 3 = speedo data face (tap toggles stock/data face, hold 2 s on the data face rotates the order up, a hold on the stock face does nothing; replaces the overlay idea), A = trip key (tap toggles ODO/TRIP, hold 2 s resets the trip only), B = tach rpm/boost. The rest are spare. Ribbon order R1..R4, C1..C4 is the common layout for these pads; confirm with a meter (press a key, find the row/col pair).

## Tach: Waveshare ESP32-S3-LCD-2.8C

| Pin | Connects to |
|---|---|
| GPIO43 (UART TXD on the SH1.0 header) | CAN board #2 CTX |
| GPIO44 (UART RXD) | CAN board #2 CRX |
| 3V3 / GND | CAN board #2 |
| USB-C (native) | PC, power + flashing (the UART USB port shares GPIO43/44 and can't be used) |

Confirm the header pin order against the Waveshare silkscreen/wiki before connecting.

## Blink PKP-2300-SI (AT04-4P on the keypad, AT06-4S plug)

| Pin | Wire | Signal |
|---|---|---|
| 1 | blue | CAN L |
| 2 | white | CAN H |
| 3 | black | GND (battery -), also tied to bench/bus GND |
| 4 | red | +12–24 V |

Pinout and defaults are from the PKP-2200-SI CANopen manual (https://blinkmarine.com/app/uploads/2024/11/PKP_2200_SI_CANopen_UM.pdf). Same product family; confirm against the PKP-2300-SI documentation. Defaults: 125 kbit/s, node 15h, key-state PDO 195h, LED command 215h. Set 1 Mbit/s (object 2010h) on the adapter alone before joining the 1 Mbit/s bench bus.

## CAN bus

USB-CAN adapter (120R switch ON) -> CAN board #1 (hub, no termination) -> Blink keypad (no termination) -> CAN board #2 (tach, 120R). Power off: about 60 ohm between H and L. If a mid-bus CAN board has a fixed 120R, remove it. Twist H with L and keep stubs short; tie all grounds together (adapter GND, both ESP32s via USB, 12 V supply negative).
